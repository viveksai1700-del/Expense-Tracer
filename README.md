# Expense Tracker
<br>
A simple Python Expense Tracker that helps you record, view, and manage your daily expenses.
<br>

# Features
➕ Add new expenses.
📋 View all expenses.
💵 Calculate total expenses.
🗑️ Delete expenses
📅 Store expense details
🖥️ Simple command-line interface
<br>

# Technologies Used
- Python 3.
- Python Lists & Dictionaries.
- Functions.
- Loops.
- Conditional Statements.
- User Input.
